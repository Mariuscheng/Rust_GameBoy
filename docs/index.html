Rust GameBoy Emulator: A.I. Assisted Journey

vibe coding • 黑底綠字 • 8-bit GameBoy 復古感

簡介

這個專案以 A.I. 指示（prompt）為核心，逐步生成並調整模擬器各個子系統（CPU、PPU、MMU、AUDIO、IO）。我會把明確的 prompt 給 A.I.，要求它生成可編譯的 Rust 函式、測試用例與 debug 建議，並用小步提交與驗證方式逐步整合到本地程式庫。

範例 A.I. Prompt

/* Prompt:
實作 GameBoy CPU 的 ALU 指令加法，使用 Rust，
包含邊界檢測、flag 更新，並提供單元測試。
請回傳完整程式碼檔案與說明。
*/
